# Kubernetes and Helm Guide
Chart: `deploy/helm/peacloud`. Replace `ghcr.io/OWNER/peacloud` before publishing. Default API replicas: 2. HPA: min 2, max 10, 70% CPU. PDB requires at least one pod available. Pods run non-root with RuntimeDefault seccomp, no privilege escalation, read-only root filesystem and dropped Linux capabilities. Supply database, Redis, OIDC and secret-store settings through Kubernetes Secrets/External Secrets rather than values committed to Git. For managed production, prefer Amazon RDS/Aurora + ElastiCache, Azure Database for PostgreSQL + Azure Managed Redis, or Google Cloud SQL/AlloyDB + Memorystore rather than in-cluster stateful databases.
